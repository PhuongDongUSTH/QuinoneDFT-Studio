# Quinone DFT Studio 2.0.0

Desktop program for Windows that screens quinones for electrochemical CO2 capture with Gaussian 16: library building (RDKit), 3D structures, Gaussian 16 inputs and parallel job control, redox potentials, CO2 binding, calibration and ranking, IR / Raman / UV-Vis spectra tools, and a built-in AI Agent that can operate the whole program.

## Download

Go to **Releases** (right side of this page) and download from **v2.0.0**:

- `Software_Installation_v2.0.0_autoinstall.exe`: automatic installation, just double-click and wait (recommended).
- `Software_Installation_v2.0.0.exe`: normal installation, you choose the folder and the options.
- `Software_Manual_v2.0.0.pdf`: full manual (English and Vietnamese).
- `QuinoneDFT_Studio_Quick_Setup_Guide.pdf`: two-page quick setup guide.

## Requirements

Windows 10 / 11 (64-bit), about 2 GB free disk space, internet during installation. Gaussian 16W is your own licence (GaussView, Avogadro 2 and Chemcraft are optional; IboView is included).
